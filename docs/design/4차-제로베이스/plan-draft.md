## 2. 제로베이스로 본 것 (폰 390 다크 첫 화면 8장 + 위 수치)

지난 차수들은 한 화면씩 문제를 고쳤다. 처음부터 다시 보면 문제는 화면마다가 아니라 **재료가 정해져 있지 않은 것**에 있었다.

1. **색이 많다.** 하늘 강조 + 초록·빨강·호박·파랑·보라 + 밑줄 파랑 링크 + 노란 별 + 노란 알림 점. 무엇이 중요한지 색이 말해 주지 못한다.
2. **모든 숫자가 고정폭 글꼴이다.** 표의 자릿수 맞춤에는 좋지만 총액·카드 숫자까지 터미널처럼 보여 "차분·정확·믿음"보다 "기계"에 가깝다. 숫자 맞춤은 일반 글꼴의 `tabular-nums`로도 된다(목업에서 확인).
3. **알약(칩)과 테두리 상자가 너무 많다.** 거르기 칩 세 줄, 보기 전환, AI 단추, 신호 칸이 모두 같은 둥근 상자라 무엇이 단추이고 무엇이 표시인지 갈리지 않는다(가짜 단추 9).
4. **왼쪽 색 띠 카드**(확인할 신호, 리밸런싱 주문 카드)는 같은 뜻을 화면마다 다른 모양으로 말한다.
5. **설명 글이 길다.** 종목 관리 맨 위 안내 4줄, 첫 화면 안내 3단계 문단. 폰 첫 화면의 절반이 글이다.
6. **같은 부품이 화면마다 다르게 생겼다.** 총 평가금액 카드(대시보드·리밸런싱), 표 머리, 빈 상태 상자, 안내 상자. CSS 한 파일 5,819줄에 이어 붙여 온 결과다.
7. **폰에서 보유 종목이 카드 목록이라** 한 화면에 셋까지 보인다. 주인이 고른 B(표 먼저)는 같은 자리에 다섯을 보인다.

## 3. 과업 흐름 (지금, 가짜 서버 주인 계정 · 폰 390 — 누른 횟수 / 화면 바뀜 / 망설인 곳)

| 과업 | 지금 | 망설인 곳 | B 방향에서 기대 |
| --- | --- | --- | --- |
| ① 오늘 할 일 5초 | 0 / 0 | "확인할 신호" 카드가 총액 위에 있어 총액을 보려면 내려야 함. 매크로 줄이 그 사이 | 요약 칸 바로 아래 신호 칸 넷 — 내리지 않고 둘 다 |

## 6. 범위와 주인에게 물을 것

**이번 묶음(1 — 전역 + 대시보드)에서 할 것**
1. CSS 쪼개기(겉모습 그대로, 커밋 하나) — `frontend/src/styles/{tokens,base,components/*,pages/*}.css`, 파일 하나 300줄 아래를 목표로.
2. 색표 `tokens.css` — 청람 #0051a8 을 가운데로 OKLCH 로 밝기 단계(50~950)를 만들고, 회색은 청람으로 살짝 물들인 단계. 다크·라이트를 같이 정한다. 출처(IBM Carbon cyan 80 의 채도를 높인 것 / Tailwind green·red)를 파일에 적는다.
3. 글꼴 — Pretendard 부분집합(KS 2,350자 + 라틴, 400~700)을 Wanted Sans 자리에. Spoqa Han Sans Neo 는 요약 숫자에만(㉣). sw.js 캐시 확인.
4. 표시 부품 `components/ui/` — `AppBar`(색 머리줄), `Tabs`(밑줄), `SummaryGrid`(요약 칸), `SignalCounts`(신호 칸 넷), `Badge`, `SignalMark`(▲▼◆), `Button`. 데이터·상태 로직은 옮기지 않는다.
5. 대시보드 포트폴리오 보기를 B 로 — 목업 `01c-B큰총액.html` 가 + 고른 글꼴·색.
6. 시그널 보기는 머리줄·탭·색만 바꾼다(배치는 묶음 2에서 목업으로).

**안 할 것(이번 묶음)**: 다른 화면 배치, 이동 경로, 시그널 로직·문구의 숫자, 토스페이스(파일 없음).

**주인에게 물을 것 (2-2 "먼저 물어야 하는 것")**
- ㉠ "AI 포트폴리오 진단"을 세 번째 탭으로(목업 B) / 지금처럼 단추로. — 탭이면 누르면 팝업 대신 화면이 바뀐다(이동 경로 변경).
- ㉡ 대시보드의 매크로 줄(VIX·금리): 목업에는 없다. 표 아래로 / 요약 칸 안 한 줄 / 대시보드에서 빼기(매크로 탭에 있음).
- ㉢ 화면 설정 "상승 색 빨강(하락 파랑)"을 남길지. 남기면 매도 빨강과 상승 빨강이 겹치는 경우를 목업으로 한 번 더 본다.
- ㉣ 스포카는 요약 **숫자만**(파일 작음, 이름표는 Pretendard) / 이름표까지(목업 그대로, 파일 큼).
- "금액 가리기"는 목업에 없지만 기능이라 남긴다 — 총 평가금액 이름표 옆 글자 단추.
