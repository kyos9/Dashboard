## 5. 글꼴

- **용량:** Pretendard 299,952B(글리프 2,543, GSUB `calt·locl·tnum`), Spoqa 숫자 2,016B(글리프 19, 숫자 폭 전부 596). Spoqa 는 빌드 CSS 안에 `data:font/woff2` 로 들어간다. 합계 301,968B → "300KB 안팎"에 든다.
- **swap:** 두 `@font-face` 모두 `font-display: swap`(tokens.css:31, :41).
- **tnum:** body `font-variant-numeric: tabular-nums`(base.css:14). 요약 숫자도 tabular-nums. audit `tnum-width` 0.
- **오프라인:** 처음 열고 다시 불러온 뒤 캐시에 `/assets/PretendardVariable-ko-…woff2`·`/assets/index-…css` 가 있다(sw.js:88 `/assets/` 캐시 먼저). `setOffline(true)` 뒤 다시 열면 `document.fonts.check('16px Pretendard') = true`. API 는 "연결 확인 중"이고, 이것은 원래 동작이다. 글꼴을 이름에 해시가 붙은 자산으로 두었으니 sw `VERSION` 은 안 올려도 된다.
- **느린 망**(지연 400ms · 50KB/s):
  - 요약이 보인 18.0초 시점에 이미 Pretendard 가 loaded 였다.
  - CLS 0.067. 큰 밀림 하나(17.8초, `section`·`signal-counts`·`money-note`)는 데이터가 도착해 생긴 것이고, 글꼴 교체 때문이 아니다.
  - 그 전 밀림은 0.0003·0.0004(머리줄 오른쪽).
