# 묶음 4 리밸런싱 — 넣기 계획 (목업 12c, 주인 "이대로 넣기" 2026-11-12)

계산 · 저장 · 상태는 RebalancePanel 에 그대로 둔다(만드는 법 — 데이터 · 상태 로직은 옮기지 않는다). 바뀌는 것은 그리기뿐이다.
새 표시 부품은 `components/rebalance/` 에, CSS 는 `styles/pages/rebalance*.css`(파일마다 300줄 아래).

## 화면 (폰 · PC 같은 순서)

1. 머리: "리밸런싱" + `다음 리뷰 D-n` 알약(리뷰 칸으로 감) + PageIntro 한 줄
2. 요약(`RebalanceSummary`): 큰 전체 자금(현금 포함) · 알약(현금 · 밴드 · 목표 합계 ≠100 이면 호박 ⚠ → 목표 · 밴드 시트)
   - 금액 가리기면 금액 숨김(지금 MoneyLine 규칙 그대로) · 환율 추정 경고는 그대로 위에
3. 줄일/늘릴 막대(`OrderSplit`): 줄일 n종목 −합 · 늘릴 n종목 +합 · 유지 n · "◆ = 비중이 밴드 밖"
4. 새로 넣을 돈 한 줄 — 누르면 지금 넣는 칸(newMoneyBlock, 팔지 않고 새 돈만 포함)이 펼쳐짐. 값이 있으면 줄에 금액
5. 줄일 종목 / 늘릴 종목 — 둥근 카드 묶음, 줄 = 왼쪽 띠(시그널 색) · ◆(비중 신호) · 이름 · `지금% → 목표%` · 오른쪽 부호 주수(−1,638주) · 금액
   - 사기 · 팔기 **글씨 없음**(주인). 색은 `--signal-buy` / `--signal-sell`(상승 빨강을 따름 — 묶음 1 넘어온 것)
   - 목표 0% 풀이 · "참고(기간 내 매도)"는 줄을 누른 시트로
6. 유지 한 줄(이름 이어 쓰기) — 누르면 그 줄들이 펼쳐짐
7. 타일 셋: 목표 · 밴드(시트) · 리뷰 · 기록(아래 칸으로) · 설정(접힌 설정 펼치고 감)
8. 리뷰 · 기록 칸, 설정(접힘)은 지금 그대로 아래에

PC: 같은 순서, 5 를 표 6열(종목 · 비중 지금→목표 · 주문(부호 주수) · 조정 금액(현지) · 신호 · 거래 입력), 팔기/사기/유지 묶음 줄. 현금 줄 · 합계 줄은 표 끝에.

## 시트 둘 (새 팝업 — 가두기 꼭: useFocusTrap · Esc · 뒤로가기 · lockBodyScroll)

- `OrderSheet` (줄 누르면): 이름 + 비중 배지 · 구분 · 수량 · 현재가 / 큰 부호 주수 + 금액(현지 금액) / 비중 지금 → 목표 · 밴드 밖이면 풀이 / 평가금액 · 목표 금액 / 참고 배지와 뜻 / 목표 0% 풀이 / 버튼 "종목 안 보기"(/stocks/:ticker) · "거래 입력"(지금 OrderTrade 그대로)
- `TargetSheet` (목표 · 밴드): 종목마다 목표 % · 밴드 %p 두 칸 + 현금 목표, 합계 줄, 저장 = 지금 saveAll(drafts) 로 target/band 만. 수량 · 평단가 · 산 환율은 종목 → 한 번에 수정 / 종목 안 보유(StockEditModal) — 리밸런싱의 보유 칸은 없앤다(주인 답)
