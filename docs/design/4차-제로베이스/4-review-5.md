- 까닭: `frontend/src/components/ui/Sheet.tsx:31` 의 Esc 처리 `e.key === 'Escape' && onClose()` 가 안쪽 팝업을 보지 않는다. - 고칠 방향: Sheet 의 onKey 에서 `ref.current && isCovered(ref.current)` 이면 그냥 돌아간다. 테스트를 하나 둔다: 시트 안 확인창에서 Esc를 누르면 확인창만 닫히고 `getByRole('dialog', {name:'리뷰 · 기록'})` 는 남는지.

- 다른 건 정상이었다: 확인창이 떠 있을 때 Tab 은 확인창 안에서만 돈다(취소 ↔ 네, 지웁니다). 뒤로가기를 누르면 확인창만 닫히고 리뷰 · 기록 시트는 남는다.
