## 4. 글꼴 (5-1) — 용량 대비 효과

| 방법 | 용량 | 비고 |
| --- | --- | --- |
| 지금(불러오지 않음) | 0 | 아이폰은 Apple SD 산돌고딕 Neo, 윈도는 맑은 고딕, 여기 검사기는 WenQuanYi. 줄바꿈 위치가 기기마다 다르다 |
| Pretendard 가변 전체 | 2,010KB | 기준 초과 |
| 굵기별 정적 subset(400·600·700) | 3 × 262KB = 786KB | 기준 초과 |
| 동적 subset(92조각) | 쓰는 글자만 받지만 화면마다 조각이 달라 오프라인에서 빠질 수 있다 | PWA에 맞지 않는다 |
| **가변 subset — KS X 1001 한글 2,350자 + 라틴·기호, 굵기 400~700** | **293KB (299,964B)** | 기준(300KB) 안이다. 2,350자 밖의 드문 글자와 일본어는 그 글자만 시스템 글꼴로 보인다 |

- 효과:
  - 모든 기기에서 같은 글꼴로 보인다.
  - 여기서 잰 줄바꿈이 아이폰과 같아진다.
  - 숫자 폭이 일정한 한글 글꼴이라 표가 고르다.
- 숫자는 지금처럼 고정폭 글꼴(`.mono`)을 쓴다(8-4 결정). 바꾸지 않는다.
- 비용:
  - 처음 한 번 293KB를 받는다. 그 뒤로는 서비스 워커가 캐시해 오프라인에서도 보인다.
  - 받는 동안에는 시스템 글꼴로 먼저 보인다(`swap`).
- 라이선스: SIL OFL 1.1. 부분집합으로 만들어 함께 배포해도 된다. 라이선스 파일을 같이 둔다.

## 6. 범위와 합격 기준

**1차에 할 것**

1. 전역
   - 글꼴(주인 승인 시)
   - 줄바꿈 규칙: `balance`·`pretty`, 묶음 클래스, `overflow-wrap: anywhere` 정리
   - 폰 입력칸 44px
   - `<a>` 강조 버튼의 대비
2. 대시보드
   - 포트폴리오 보기·시그널 보기의 첫 화면 정돈(시안)
   - PC 시그널 표 머리
   - 첫 화면(종목 0)의 버튼

**1차에 안 할 것**

- 재무·리밸런싱·종목 관리·매크로·팝업의 화면별 정리(2차부터). 다만 전역 규칙은 이 화면들에도 퍼지므로 회귀는 잰다.
- 기능 추가(매도 시그널 필터 등).
- 헤더 버튼 이름.

**합격 기준**은 DESIGN_PROMPT 6장 그대로다. 1차에서는 대시보드 화면 묶음에 이렇게 적용한다.
