# 디자인 2차 — 문구 변경 표

전 → 후 → 이유. 테스트가 그 문구로 요소를 찾으면 같은 줄에 적는다(지우거나 건너뛴 테스트 없음).

## 묶음 A — 시그널 화면

| 자리 | 전 | 후 | 이유 | 테스트 |
| --- | --- | --- | --- | --- |
| 시그널 보기 · 신호 거르기 | (없음) | `▼ 매도 n` 칩 | 신호 요약에 "매도 n"이 있는데 거를 길이 없었다 (주인 결정 ①) | `Dashboard.test.tsx` "매도 거르기 — …" (새) |
| 신호 요약 칸 | 글자만 (단추처럼 생겼는데 반응 없음) | 매수·매도·비중조절 칸이 단추 — 누르면 그 거르기, 다시 누르면 모두 보기. 관망은 그대로 글자 | 계획 검토(사용자) U1, 주인 결정 ① | "신호 요약의 … 칸을 누르면" (새) |
| 시그널 보기(폰) | 보기 단추 다섯이 늘 보임 | `보기·설정 ⋯` 를 누르면 펴진다(순서 편집·종목 설정 중에는 펴진 채) | 필터 네 줄 → 세 줄 (주인 결정 ①) | "폰의 순서 편집" — 펴는 단계를 더함(고친 테스트 1) |
| 카드 | 신호등, 그 아래 비중 배지(이름표 없음) | 왼쪽 이름표 `시그널` · `비중` · `매수 조건 n/전체` | "▼ 매도 ◆ 매수 검토"가 "팔라는데 사라고도?"로 읽혔다 (시안 v4, 주인 결정 ①) | "카드: 시그널 · 비중 · 매수 조건 줄" (새) |
| 카드 | 조건 칩이 지표 상자마다 | `매수 조건 n/전체` 한 줄, 규칙의 조건 전부 | 거래량 "한산" 밑에 ✓ "변동성·거래량"이 어긋나 보였다, 칸 없는 조건이 안 보였다 | 같은 테스트 |
| 시그널 보기 아래 설명 | "각 조건은 해당 지표 칸에 ✓로 표시됩니다." | "표에서는 각 조건이 해당 지표 칸에, 카드에서는 "매수 조건" 줄에 ✓로 표시됩니다." | 카드에서 칩 자리가 바뀌었다 | 설명 줄 테스트는 앞부분(`buyRuleSentence`)만 본다 — 그대로 통과 |
| 시그널 표 | (칸 없는 조건은 표에 없음) | `그 밖의 조건` 칸 — 그런 조건이 있을 때만, 200일선 뒤 | 칸 수에 묶이지 않게 (PROMPT 0장, 계획 검토 D2) | "정의가 바뀌면 …" 에 단언 셋 더함 |
| 차트 팝업 제목 | `VOO` `VOO` | `VOO` (이름 = 티커면 한 번). 불러오는 틀도 같게 | 군더더기 | `ChartModal.test.tsx` "이름이 티커와 같으면 …" (새) |
| 차트 팝업 | (근거 없음) | 차트 위 `매수 조건 n/전체` 한 줄 — 대시보드에서 열 때만 | 과업 3 이 팝업 안에서 끝나게 (주인 결정 ①) | "대시보드에서 열면 …" (새) |
| 차트 범례 | `매수 13구간 · 43일` | `매수 43일 (13번)` + 툴팁 "시그널이 뜬 날 수 — 괄호는 며칠 이어서 뜬 것을 한 번으로 센 횟수(차트의 점 하나가 한 번)" | "구간"을 몰랐다 | `ChartLegend.test.tsx` "구간 대신 날 수가 먼저" (새) |

색만 바뀐 것(문구 아님): 시그널 표의 "추세 형성"·"거래량 증가" 값 칩 — 파랑 → 테두리 강조(상승 색 빨강에서 하락 파랑과 같았다).
