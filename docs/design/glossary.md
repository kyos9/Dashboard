# 용어 사전 (디자인 차수 공통)

차수에 묶이지 않는다. 1차(`01-기획.md` 5장)에서 정한 것을 옮겨 오고, 2차에서 더한 것은 *(2차)* 로 적는다.
화면 글자를 새로 쓰거나 옮길 때 이 표를 따른다. 시그널 임계값 숫자는 여기 적지 않는다 — `frontend/src/lib/display.ts` 의 조건 정의(서버 `signal_rules`)에서 나온다.

| 하나로 | 대신 쓰지 않는 말 | 비고 |
| --- | --- | --- |
| 종목 | 티커(입력칸 도움말에서만 "티커") | "이름이나 티커로 찾기"는 그대로 |
| 시그널 | — | 무릎매수·어깨매도. **매수 시그널 · 매도 시그널** |
| 신호 | — | 비중조절과 묶음을 가리킨다. **비중조절 신호**, "확인할 신호", "신호 요약" |
| 수정 | 편집 | 값을 바꾸는 것: "✎ 수정", "종목 한 번에 수정". "순서 편집"은 끌어 옮기기라 그대로 *(2차에 다시 봄 → 그대로)* |
| 설정 | — | 화면·알림·AI 키 같은 기기·계정 설정. 시그널 보기의 "⚙ 종목 설정"(감추기·비중·순서) |
| 저장 | 적용 | 서버에 남는 것. "적용"은 저장 없이 화면에만 바로 걸리는 곳에만 |
| 화면 설정 | 화면(PC 헤더) | PC 버튼 이름을 폰 메뉴와 맞춘다 |
| 로그아웃 | 나가기 | 화면 글자에 둘이 섞여 있다 |
| AI 키 설정 | AI(PC 헤더) | *(2차)* PC 헤더 버튼 "AI" 는 무엇을 하는지 모른다 |
| 종목 추가 | 관심 종목 추가 | *(2차)* 그 칸에 보유 수량·평단가도 있다. "관심 종목"은 대시보드에서 **보유 0 인 종목**을 뜻하므로 그 뜻으로만 쓴다 |
| 사기 / 팔기 / 유지 | 매수 (BUY) / 매도 (SELL) / 유지 (HOLD) | *(2차)* 리밸런싱 **주문**. 폰 카드는 이미 "사기·팔기". "매수·매도"는 시그널의 말이라 주문과 섞이면 "매수 시그널이 떴다"로 읽힌다 |
| 비중 초과 / 비중 미달 | 매도 검토 / 매수 검토, 과중 | *(0.44.0)* 비중조절 배지. **상태**로 말한다 — "검토"는 지표 시그널의 "▼ 매도 / ▲ 매수"와 겹쳐 "팔라는데 사라고도?"로 읽혔다. 서버의 사유 글(`밴드 초과(매도 검토)`)은 그대로 두고 화면에서만 바꾼다 |
| 신호 (표 머리) | 종합 신호등 | *(0.44.0)* 대시보드 표의 그 칸. 안에 이름표 두 줄 — "시그널"(지표) / "비중"(비중조절, 있을 때만) |
| 기간 내 매도 | — | 리밸런싱에 붙는 어깨매도(참고) 배지. 주문(사기)과 같은 줄에 있을 때 "참고 신호"로 묶어 보인다 *(2차)* |
| 리뷰 기록 / 평가금액 기록 | 기록(둘 다) | *(0.45.0)* "지금 상태 기록하기"로 남기는 것은 **리뷰 기록**, 서버가 매일 아침 남기는 것은 **평가금액 기록**("평가금액과 보유 모습" — 방침과 같은 말). 쌓인 것은 "○일치"(줄 수라 "○일째"가 아니다) |
| 버리고 닫기 / 계속 고치기 | 취소(확인 창에서) | *(0.45.0)* 저장하지 않은 것을 버릴지 묻는 창. 머무는 쪽 단추가 "취소"면 "닫기 취소"인지 "고친 것 취소"인지 모른다 |
| 밖에 꺼낸 백업 | 오프사이트, 외부 백업 | *(0.45.0)* 진단의 백업 칸 "밖에 꺼낸 것: 마지막 …(관리자 PC)". 서버 안 7벌과 구분 |
| 매도 조건 (참고) | 어깨매도 조건 | *(0.45.0)* 차트 팝업, 매도(참고) 신호가 켜진 날만. "매수 조건 n/4"와 짝. 칩은 회색(충족도 초록·빨강 아님) — 팔라로 읽히는 색을 쓰지 않는다. 조건 이름은 서버 규칙 그대로 |
| 받을 때 — 아침 (7:30쯤) / 오후 (4시쯤) | 조용한 시간, 방해 금지 | *(0.45.0)* 🔔 알림 설정. 알림이 가는 때가 둘뿐이라 시각이 아니라 둘 중에서 고른다. 받지 않는 때 생긴 신호는 다음에 받는 때(그때도 켜져 있으면) |
| 빼기(−) · 맨 앞에만 · 소수점 · ‘만·억·천’ · 지금 값 | 음수, 정수, 단위 | *(0.45.1)* 숫자 칸이 버린 것을 알리는 화면 위 한 줄 — "〈칸 이름〉 — 빼기(−)는 넣을 수 없습니다 · 지금 값 3", 음수 칸이면 "빼기(−)는 맨 앞에만 쓸 수 있습니다". "정수만"은 초보에게 어렵고, "소수점을 뺐습니다"는 7 로 읽혀(실제 75) "숫자만 이어 붙였습니다 · 지금 값 75" |
| 서버 로그 · 백업 확인 필요 | 최근 기록에 | *(0.45.1)* 진단 맨 위 요약. 무엇을 센 것인지("서버 로그")를 말하고, 백업 칸에 경고가 있으면 "· 백업 확인 필요" — 아래 "평가금액 기록"과 "기록"이 겹쳤다 |
| 모두 다시 받기 | 모두 켜기, 음소거 해제 | *(0.45.1)* 🔔 종목별 알림, 끈 종목이 보일 때만 |
| 판 수량이 아닙니다 · 팔았으면 ‘팔았다’를 고르세요 | 누적, 순수량 | *(0.45.2)* 숫자 칸 줄의 꼬리 — 보유 수량에 빼기를 쳤을 때 / 거래 입력 "샀다"에 빼기를 쳤을 때만. "지금 가진 전체 수량을 넣습니다"는 "지금"이 "지금 값"과 겹치고 주어가 갈렸다 |
| ○종목을 저장했습니다 | 저장 완료 | *(0.45.2)* 일괄 수정을 닫은 뒤 수정 단추 아래. 셋까지 이름("SCHD 1종목", "SCHD·삼성전자 2종목"), 넷부터 "SCHD 외 3종목" |
| 새로 넣을 돈 ₩X 반영 | — | *(0.45.2)* 주문 가이드 맨 위 줄과 같은 말을 칸 아래 풀이 앞에도. "₩75 를 넣어 …↑"는 조사가 틀리고 PC 에서 방향이 틀렸다 |
| 백업 확인 필요 — 아래 백업 칸 | — | *(0.45.2)* 진단 요약의 꼬리(노랑 굵게). 무엇을 볼지 말한다 |
| ○개 보관(최대 7개) | 벌 | *(0.45.2)* 진단의 백업 개수. "벌"이 낯설었다. 문서(README·DEPLOY)의 "벌"은 그대로 |
| ◀ ▶ (이전 거래일 · 다음 거래일) · 전체 보기 | 하루 앞·뒤, 초기화 | *(0.45.2)* 차트 위 날짜 줄 옆. 고른 뒤 날짜 줄 풀이는 "(▶ 나 오른쪽 끝을 누르면 마지막 날)" — 풀이가 빠지면 폰에서 줄이 뛰었다. "앞"이 지난날·앞날로 갈리고 주말을 건너뛰어 "하루"가 아니다. "전체 보기"는 밀거나 키운 뒤에만 |
| 비중 초과 N · 비중 미달 N (칩) | — | *(0.45.3)* 신호 요약, 누르면 그 종목만. 아래 칩 줄에서는 "비중조절 · 초과 N" |
| 지금 x% · 목표 y% · +d%p (허용 ±z%p) | 현재 비중 | *(0.45.3)* 카드 비중 줄 끝. 리밸런싱과 같은 수(현금 포함 전체 대비), 밴드를 같이 — "왜 이 종목만 미달?" |
| 매수 조건 n/4 · MM-DD ▾ · ○○ 기준 | — | *(0.45.3)* 차트 팝업 조건 줄 이름표 단추. 펼치면 "✓ 충족 · 이름: 풀이". 기준일은 지표의 날(차트에서 고른 날이 아니다) |
| ▲ 매수 시그널 · ▼ 매도 시그널(참고) | — | *(0.45.3)* 차트 날짜 줄, 그 날이 시그널 날일 때 |
| 이미 담은 종목 중 같은 업종 | 익스포저, 편입 판단 | *(0.45.4)* AI 종목 분석 6절(관리자가 아닌 사람). 이름·비중 사실만. 관리자는 자기 틀 그대로 |
| 모든 기기에서 나가기 | 전체 로그아웃 | *(0.45.4)* 폰 계정 메뉴의 나가기 아래, PC 는 이름 단추(▾) 안. 다른 기기의 로그인·알림이 다 꺼진다 |
| 목표 0%라 전부 파는 계산입니다 | 목표 미설정 | *(0.45.4)* 주문 가이드의 팔기 줄 꼬리(목표 0%). 계산은 그대로, 말만 더한다 |
| 종목별 알림 | 알림 음소거 | *(0.45.0)* 🔔 알림 설정의 접힌 칸. 끈 종목은 매수 시그널·비중 알림이 오지 않는다(리뷰는 그대로) |

## 어려운 용어를 풀이할 자리

| 용어 | 자리 |
| --- | --- |
| 이격도 | 시그널 표 머리 툴팁 + 범례, 카드의 지표 이름 옆 풀이 줄 |
| ADX, DI | 같은 자리 |
| 밴드 | 리밸런싱 "자세히" |
| 비중조절 | 보유 목록 아래 모양 풀이(있다) |
| 구간 *(2차)* | 차트 범례에서 "구간"이라는 말을 없앴다 → "매수 43일 (13번)" — 날 수가 먼저, 괄호는 며칠 이어서 뜬 것을 한 번으로 센 횟수. 풀이는 범례 툴팁 |

## 기호

| 기호 | 쓰임 |
| --- | --- |
| `·` | 같은 줄의 나란한 조각 사이 ("VOO · 40주 · $96.83") |
| `—` | 앞말을 풀거나 덧붙일 때 한 번 |
| `—` (흐린, 시그널 자리) | *(0.44.0)* 관망(매수·매도 조건 미충족). 글자 대신 흐린 줄표로, 풀이는 툴팁·읽어 주는 이름·시그널 보기 아래 풀이 한 줄(폰·키보드는 툴팁을 못 본다) |
| `→` | 이동(링크)과 "지금 → 목표" |
| `↓` | 같은 화면 아래로 내려가는 링크 |
| `⋯` | 폰 메뉴(헤더)에만. 펼치기에는 쓰지 않는다 — 그건 ▾/▴ ("보기·설정 ▾") |
| `✕` | 팝업 닫기 |
| `▲ ▼ ◆` | 매수 · 매도 · 비중조절 (SVG, 글자와 함께) |

## 어포던스 *(2차, 주인 요청)*

| 꼴 | 뜻 |
| --- | --- |
| 테두리·바탕이 있는 둥근 상자(44px) | 누르는 단추. 누르지 않는 것에는 쓰지 않는다 — 상태 표시는 점 + 글자, 숫자 칸은 상자 없이 |
| 밑줄 친 이름 | 누르면 그 종목의 차트(대시보드·재무에서 같은 꼴). 누르지 않는 이름(리밸런싱 표 등)에는 밑줄이 없다 |
| 끝의 `›` | 누르면 그쪽으로 걸러지거나 넘어간다 |
| `▾` / `▴`, `▸` | 눌러서 펼친다 / 접는다 |
| 작은 칩·배지(28px 안팎) | 표시만. 누르지 않는다 |
