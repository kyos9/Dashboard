# 디자인 3차 — 끝 보고 (0.46.1)

## 한 줄

아이폰 홈 화면 앱에서 **팝업 위쪽이 시계·배터리와 겹치고 잘리던 것**을 고쳤습니다. 팝업을 내려도 제목·✕ 가 위에 남고,
종목 관리·리밸런싱 같은 일반 화면을 내려도 상태바 밑으로 내용이 비쳐 들어가지 않습니다. **CSS 만** 바꿨습니다(서버·데이터 그대로).

## 아이폰·갤럭시에서 직접 확인할 것 (여기서는 사파리·삼성 인터넷을 못 띄운다)

1. **아이폰 홈 화면 앱**으로 ⋯ → 알림 설정 / 진단 / 화면 설정 / AI 키: 제목·✕ 가 시계 밑에서 시작하나, 끝까지 내려도 남나.
2. 대시보드 → 종목 한 번에 수정: 내려도 제목·✕ 가 위, 저장 단추가 아래(홈 표시줄 위)에 있나. 칸을 눌러 키보드가 떴을 때 칸이 가려지지 않나.
3. 종목 관리·리밸런싱을 끝까지 내리기: 시계·배터리 자리에 표가 비치지 않나. **라이트 테마**에서 상태바의 흰 글자가 흰 띠 위에서 보이나(검토자 참고 — 여기서는 못 봄).
4. 폰을 가로로 돌려 차트·일괄 수정: 노치에 제목·✕ 가 가리지 않나.
5. 갤럭시(삼성 인터넷·크롬): 팝업이 전과 같은가(안전영역이 0이라 바뀔 것이 거의 없다).
6. ⋯ → 모든 기기에서 나가기: 확인창이 가운데 카드로, 위에 빈 줄 없이 뜨나(누르지 말고 취소).
