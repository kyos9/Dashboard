# 디자인 3차 — 계획 초안 (폰 팝업 위쪽)

> **순서가 거꾸로 된 부분을 먼저 밝힌다.** 주인의 첫 두 요청 때는 이 절차 없이 고쳤다
> (`2932bca` 안전영역 — PR #23 으로 이미 main 에 들어감, `20db93f` 머리줄 ✕).
> 주인이 "Main 의 규칙대로"라고 한 뒤로 이 차수를 열었다. 그래서 이 초안은 **이미 고친 것까지 포함해** 계획 검토를 받고,
> 검토에서 나온 것은 실행으로 되돌린다. 비교 기준은 **PR #23 이 들어가기 전의 main(`87ed4ff`)이 아니라 지금의 main(`b3a2d5e`)**이다 —
> 이미 합쳐진 첫 고침은 되돌리지 않고 그 위에서 잰다. 위쪽 겹침 자체의 전후는 PR #23 에서 손으로 확인했다(390×844, 47px 흉내).
