## 사용자별 메모

### 주인 (owner, 아이폰 390 · PC)
- **막힌 곳**: 없음.
  - 알림 설정은 4번 눌러 끝났다: ⋯ → 알림 설정 → 종목 체크 하나 끄기 → ✕.
  - 진단도 4번이다: ⋯ → 진단 → 전체 → ✕.
  - 뒤로 가기로도 팝업이 닫힌다(알림·차트 모두).
- **좋아진 곳**
  - 진단의 ✕ 높이가 다른 팝업과 같아졌다(전부 y63). 팝업을 바꿔 열어도 같은 자리를 누르면 된다.
  - 일괄 수정(15종목)을 아무리 내려도 제목·"15종목"·✕ 가 위에 있다(`36-owner-360-dark-bulk-open.png`).
  - 대시보드를 내려도 상태바 자리가 비치지 않는다(`60-owner-360-dark-chart-longname.png` 뒤 화면).
  - 가운데 확인창(모든 기기에서 나가기)은 화면 가운데에 있고 상태바와 멀다(`62-owner-360-dark-confirm-card.png`).
  - PC 1400 과 확대 150% 의 팝업은 위아래 20px 씩 띄워져 다 들어온다(`66-owner-zoom150-alert.png`, `67-owner-zoom150-bulk.png`, `66-owner-pc1400-alert.png`).
- **나빠진 곳**: 못 찾음.
- **헤맴**: 진단은 머리줄(제목 + 요약 두 줄 + 칩)이 고정이라 화면을 많이 쓴다. 아래 '로그 파일 받기' 줄도 고정이다. 그래서 360×780 에서는 내용이 보이는 높이가 화면의 절반 남짓이다(`21-owner-360-light-diag-all.png`).

### 사용자 (friend, 갤럭시 360 한 손)
- **막힌 곳**: 없음.
  - 대시보드의 '✎ 수정' → 아래 종목(삼성전자) 보유 수량을 눌러 100→101 → '1종목 저장'. 저장하자 팝업이 닫혔다(`33-…-typed.png` → `35-…-saved.png`).
  - 수량을 고치면 저장 단추 글자가 "저장"에서 "1종목 저장"으로 바뀌고 진해진다. 고쳤는지 바로 알 수 있다.
- **좋아진 곳**
  - 입력칸을 눌렀을 때 머리줄 밑에 숨지 않는다. 일부러 입력칸을 머리줄 뒤로 밀어 넣은 뒤 Shift+Tab(폰 키보드의 '이전'과 같음)으로 가면, 화면이 내려와 칸이 머리줄 바로 밑(y119, 머리줄 끝 115)에 보인다(`37-owner-360-dark-bulk-focus-12.png`, `…-30.png`).
  - 종목 관리·리밸런싱을 끝까지 내려도 시계·배터리 자리에 글자가 겹치지 않는다(`43-friend-360-dark-rebal-end.png`, `46-friend-360-dark-manage-end.png`).
- **나빠진 곳**: 못 찾음.
- **거슬림**
  - 일괄 수정에서 반대 방향은 숨는다. 아래 저장 줄 뒤에 있는 칸으로 Tab(키보드 '다음')해 가면 화면이 따라 내려가지 않는다. 고른 칸(AAPL 밴드)이 안내문·저장 줄 밑에 가려진 채 남는다(`38-owner-360-dark-bulk-focus-down.png`).
    - 360×780 에서 저장 줄은 안내문 두 줄을 포함해 160px 다.
    - 손가락으로 직접 누르는 경우는 해당 없다.
    - 실제 폰 키보드가 떴을 때 어떤지는 이 환경에서 못 봤다.
  - ✕ 는 여전히 엄지에서 가장 먼 오른쪽 위다. 계획에서 다음 차수로 미룬 것이고, 뒤로 가기로 닫힌다.

## 요약
- **막힌 곳 0. 첫인상 5개 맞음.**
  - 알림은 "꺼짐" 상태로만 확인했다. "켜짐"은 이 환경에서 만들 수 없었다.
  - 손님·승인 대기 행은 정답의 전제가 다르다(승인 대기도 화면 설정을 연다).
- 계획 검토 때 이 입장이 낸 걱정은 둘 다 풀렸다.
  - U1(일반 화면을 내리면 상태바 밑이 잘림): 종목 관리·리밸런싱·대시보드·손님 화면에 상태바 띠가 있다.
  - U2(일괄 수정의 머리줄): 내려도 제목·✕ 가 남는다.
- 남은 거슬림은 하나다. 일괄 수정에서 아래로 Tab 하면 칸이 저장 줄 밑에 숨는다.
