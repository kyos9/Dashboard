## 새 버전과 옛 버전 비교 (요약)
- **글은 같다.** 시그널 보기(표·카드), 열 머리 조건식(`< 0`, `> 20`, `-DI > +DI`, `변동성↓ 또는 >1.1`), ✓ 표시, 아래 설명 줄, 종목 팝업 AI 탭, AI 전체 정리, AI 포트폴리오 진단, 리밸런싱 주문 가이드, ✎ 수정, 금액 가리기, 새 사용자·승인 대기·손님 화면의 화면 글을 두 버전에서 따로 뽑아 비교했고 모두 같았다(다른 곳은 머리의 `v0.41.0` 표시뿐).
- **자리도 같다.** PC 1400 다크/라이트(상승 빨강), 아이폰 390 다크(빨강)/라이트, 확대 150%(933px·1.5배), 갤럭시 360 다크 전체 화면을 픽셀로 비교했다. 버전 표시 몇 픽셀 말고는 차이가 없었다(아이폰 설명 줄 한 줄에 글자 가장자리 수준 차이만 있었고, 눈으로는 같다). 가로 스크롤은 없었다.
- 새 버전에는 조건 정보를 주는 응답이 새로 있다. 손님과 승인 대기는 그 응답을 받지 못했고(401), 화면에 조건 글도 새어 나오지 않았다.

## 참고 (사용 환경)
- 아이폰 390에서는 "화면" 설정이 오른쪽 위 ⋯ 메뉴 안의 "화면 설정"에 있다. PC처럼 위에 바로 보이지 않는다(찾을 수는 있었다).
- 상승 색 설정은 기기마다 저장되어 새 브라우저에서는 다시 초록으로 시작한다(설명대로 "이 기기에만 적용").
- 가짜 서버의 데이터는 실행 중에 이어져, 회귀 3에서 고친 수량이 뒤 화면 총액에 반영돼 있다(두 버전 모두 같은 수정을 했다).
- 띄운 서버: 8193(PID 16606), 8196(PID 16608). 둘 다 PID로 껐고 꺼진 것을 확인했다. 처음 적어 둔 PID 16604·16605는 서버를 감싼 셸이었다.
