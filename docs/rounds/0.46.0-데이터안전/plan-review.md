# 0.46.0 계획 검토 — 검토자 (읽기만)

대상: `plan-draft.md`. 규제 영향 "없음"에 **찬성**한다. 사용자에게 보이는 판단·숫자가 늘지 않고, 새 정보는 관리자 전용이다. 새 표·마이그레이션이 0이고 `refresh_status` 는 공용이며 다시 만들 수 있는 값이라는 판단에도 **찬성**한다.

## A1 복구 시험
- 찬성: 표 목록을 `Base.metadata` 에서 읽는다. 도구가 없으면 건너뛰지 않고 실패한다. DEPLOY 10-1 명령 그대로 붓고 시퀀스까지 본다.
- 걱정(고쳐야 함): "마지막 줄을 자르면 붓기가 실패한다"는 완료 조건은 믿을 수 없다. plain 덤프의 끝은 `-- PostgreSQL database dump complete` 주석과 빈 줄이라, 잘라도 psql 은 성공한다. COPY 블록 중간에서 끊겨도 EOF 를 데이터 끝으로 받아 일부 줄만 들어갈 수 있다. 감사가 지적한 "받은 덤프는 크기만 본다"(review.md:13, `backup-export.sh:45-49`)도 이 항목에서 풀리지 않는다.
  - 제안: `_backup_postgres` 가 끝난 뒤 끝 줄 표지를 확인하고, 없으면 실패 갈래로 보낸다. 시험은 "중간을 자른 덤프 → 표지 검사가 거절" + "줄 수 대조가 모자람을 잡음"으로 바꾼다.
- 걱정(참고): docker.yml 의 판 확인은 "같은 큰 판"보다 "**compose 서버 판 이상**"이어야 한다. 새 클라이언트는 옛 서버를 덤프할 수 있다.

## A2 pg_dump 시간 한도
- 찬성: 기본 600초라 지금보다 나빠지지 않는다. 숫자가 아닌 값은 기본값으로 둔다(지금 `KEEP` 은 `int()` 에서 넘어진다 — `backup.py:36`).
- 걱정(참고): `TimeoutExpired` 는 지금 `_failure_kind`(`backup.py:144-160`)에서 "알 수 없는 오류"로 빠진다. 새 갈래를 꼭 넣어야 한다. 이 예외의 글에는 명령줄(접속 주소의 사용자·호스트·DB 이름)이 들어 있으므로 진단 `reason` 에는 갈래 이름만 담는다. `MigrationBackupFailed` 글(`backup.py:402`)은 로그에만 남는지도 확인한다.

## A3 백업 세는 법
- 걱정(**막음**): "최근 7일치"가 **달력 7일**인지 **백업이 있는 서로 다른 날 7개**인지 정해지지 않았다. 달력으로 하면 매일 백업이 8일 실패한 뒤 첫 성공의 `prune()`(`backup.py:274-276`)이 지난 매일 백업을 다 지워 **한 벌만** 남는다. 지금은 개수로 세므로 7벌이 남는다 — 기본값이 지금보다 나빠진다.
  - 제안: 매일 백업은 "서로 다른 날 7개", 업데이트 직전 백업만 달력 7일로 센다. 실패가 이어진 동안에는 지우지 않으므로 방침의 "최대 7일"은 "보통 7일, 백업이 멈춘 동안은 더"로 고친다. 시험에 "8일 실패 뒤 성공 → 7벌 남음"을 더한다.
- 걱정(고쳐야 함): `keep` 의 뜻이 "벌"에서 "날"로 바뀐다. 화면은 `"${count}개 보관(최대 ${keep}개)"`, "(위 개수에 들어 있습니다)"를 보인다(`DiagnosticsModal.tsx:185,190`). 바뀐 뒤에는 `count`(premigrate·오늘 것 포함)가 `keep` 을 넘어 옛 화면·새 화면 모두에 "12개 보관(최대 7개)"가 뜬다. 응답 뜻을 바꾸지 않는다는 규칙(RULES "옛 화면 ↔ 새 서버")에 걸린다.
  - 제안: 새 필드를 더하고(`daily.count`, `keep_days` 등) 새 화면 문구를 바꾼다. 옛 화면에 남는 어긋남은 끝 보고에 적는다.

## A4 PC 사본
- 찬성: 같은 PC 에 서버 키가 있다는 분석, 잊을 암호를 만들지 않는 추천.
- 걱정(고쳐야 함): "OneDrive 아래면 멈춘다"는 이미 그 자리를 쓰는 사람의 **밖으로 꺼내기를 멈춘다**. 작업 스케줄러가 `/quiet` 로 돌리면 아무도 메시지를 보지 못하고, 10일 뒤 점(`backup.py:341`)으로야 안다. `icacls` 는 exFAT·FAT32 USB 와 네트워크 드라이브에서 실패한다 — USB 는 그럴 법한 꺼내기 자리다. 그때 받기를 멈추면 안 된다.
  - 제안: 권한을 못 걸면 경고만 하고 받기는 계속한다. OneDrive 거절은 처음 설정 때만 하고(이미 받던 자리는 경고+진단 문구), 기존 파일까지 `/T` 로 건다. 스케줄러를 다른 계정으로 걸었을 때 `%USERNAME%` 만 주면 주인이 못 여는 경우를 주인 확인 목록에 넣는다.

## B 헬스체크
- 찬성: 오류 글을 빼고 `db` 만 더하는 503. 잠긴 상태에서도 비밀이 없다.
- 걱정(고쳐야 함): 구글 모드에서는 문지기가 handler **앞에서** DB 를 본다(`routers/auth.py:444-447` → `_session_user` 의 `db.get`, `:94`). 쿠키가 있는 요청(화면 헤더)은 DB 가 죽으면 503 이 아니라 **500** 이다. 쿠키 없는 컨테이너 헬스체크만 503 에 닿는다. 완료 조건의 "엔진을 망가뜨린 시험"이 열린 모드에서만 돌면 이 길을 못 본다.
  - 제안: 시험을 구글 모드 + 쿠키로도 돌린다. 문지기가 `/api/health` 에서 DB 오류를 만나면 손님으로 넘기거나, 500 도 받아들이고 그렇게 적는다.
- 걱정(참고): `connect_timeout=5` 는 헬스체크만이 아니라 **모든 접속**에 걸린다. 엔진의 `connect_args` 로 넣고 기존 `DATABASE_URL` 의 값과 겹치지 않게 한다. 풀이 바쁘면 `SELECT 1` 이 풀 대기(기본 30초)에 걸려 5초 한도로 unhealthy 가 된다. 의도인지 적는다.

## C 시세 받기 실패
- 찬성: 관리자 전용, 실패 종목 최대 10개, 외부 호출 0, 새 종류를 만들지 않아 옛 화면이 넘어지지 않는다(`alerts.py:36-37,74`), `.env` 끄기 스위치.
- 걱정(고쳐야 함): 켤 때 따라잡기는 뒤처진 시장만 받는다(`pipeline.py:179-194`). 받을 종목이 0인 실행이나 일부만 받은 실행이 "막힘 아님"으로 덮어쓰면, 막힘 → 풀림 → 막힘이 되어 **푸시가 또 간다**. 제안: `total==0` 이면 적지 않고 상태도 바꾸지 않는다. 시험에 "막힌 채 재시작 → 푸시 0"을 넣는다.
- 걱정(고쳐야 함): 오류만 센다. 제공자가 **오류 없이 묵은 줄**을 주면(감사 10번의 "묵은 값") 잡지 못한다. 제안: "마지막으로 받은 때"는 호출 성공 시각이 아니라 `stale_markets`(`pipeline.py:147`)와 같은 기준(최신 시세 날짜 대 마지막 거래일)으로 판정한다.
- 걱정(고쳐야 함): `refresh_attention` 을 `/api/auth/status` 에 더할 때 `backup_attention` 처럼 관리자 갈래 안에 두고, 깨진 JSON·DB 오류에서는 점만 포기한다(`routers/auth.py:198-203`). 로그인 응답이 넘어지면 안 된다.
- 걱정(참고): 22:30 매일 잡은 `market=None` 으로 모든 시장을 한꺼번에 받는다(`scheduler.py:88-91`). 시장별로 기록하려면 결과를 종목의 시장으로 나눠야 한다. `providers` 에는 이름만 담고 `error` 글은 담지 않는다(URL·키가 들 수 있다).

## D 계정 지우기
- 찬성: active 409(두 단계), 관리자 403, 탈퇴와 같은 함수, 격리 표, `user_id` 표 전부 0 확인(`test_isolation.py:770-800` 방식).
- 걱정(고쳐야 함): 방침 5절의 백업 문장(`Policy.tsx:135-137`)은 **탈퇴**에만 걸려 있다. 관리자가 지운 계정도 서버 백업에 남고(A3 결과에 맞춰) PC 사본 4벌에도 남는다는 것을 3절에 더하는 문장과 같이 적는다.
- 걱정(참고): 응답 코드를 200 과 204 중 하나로 정해 완료 조건에 적는다. SQLite 는 마지막 id 를 지우면 그 id 를 다시 쓴다. 쪽지가 `google_sub` 를 함께 보므로(`routers/auth.py:95`) 남이 들어오지는 못한다. 같은 사람이 옛 쪽지로 승인 대기 상태로 돌아오는 정도라 적어만 둔다.
