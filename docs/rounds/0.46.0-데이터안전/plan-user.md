2. **PC 사본 (가)** — 찬성. (나)는 잊으면 끝이고, (다)는 백업이 가장 필요한 때(PC 를 다시 깐 날) 못 연다. 단 위 A4 의 "갑자기 멈춤"을 쉬운 말로 풀어 줄 때만.
3. **합치는 때: 배포하고 며칠 뒤** — 찬성. 주인의 "쓰면서 불편한 점" 칸이 비어 있는 것도 0.45 를 아직 못 써 봐서다(PROMPT.md).

요약: 막는 걱정은 없다. "고쳐야 함"은 모두 **화면 말 표에서 빠진 문구**(진단 백업 줄, 알림 풀이, 사용자 목록 풀이)와 **비개발자 말**(pg_dump, 거절과 지우기의 차이), 그리고 **⋯ 숫자와 점이 겹치는 것**이다.
