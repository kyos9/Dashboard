## 과업별로 본 것

1. **지인 360, "종목 한 번에 수정"에서 보유 수량에 "-3"**: "-" 를 누르는 순간 맨 위에 "VOO 보유수량 — 빼기(−)는 넣을 수 없습니다 · 지금 값 없음", "3" 을 치면 "… · 지금 값 3". 칸에 포커스가 있는 동안은 6초가 지나도 남아 있고, 다른 칸으로 옮기면 사라진다. 저장 단추에 "1종목 저장". 저장하니 목록이 "3주"(원래 10주). 다크도 같음. 이미 3주인 종목에 "-3" 을 치면 바뀐 게 없어 저장 단추가 꺼진다.
2. **주인 PC 1400·아이폰 390, "이번에 새로 넣을 돈"에 "7.5" → "100만"**: "." 에서 "소수점은 넣을 수 없어 숫자만 이어 붙였습니다 · 지금 값 7", "5" 뒤에 "지금 값 75". 표 위에는 "새로 넣을 돈 ₩75 반영 — 전체 자금으로 목표 비중을 다시 맞춘 주문입니다". "만" 에서 "‘만·억’ 은 읽지 않습니다. 0 을 모두 쳐 주세요 · 지금 값 100", 표 위에는 "₩100 반영". 1000000 을 치면 칸에 "1,000,000", "₩1,000,000 반영"이 나오고 VOO 가 636주에서 637주로 바뀐다. 무엇으로 계산했는지는 "₩… 반영" 줄을 보면 알 수 있다.
3. **주인, 매크로 CPI 예상치 "-0.2"**: 받는다. 저장 뒤 "2026-10 예상 -0.20% 직접 입력 · 아직 발표 전". 폰 360 다크(근원 CPI)도 같다. **시그널 기준, 비교 기간(거래일) "7.5"**: "." 에서 "소수점은 넣을 수 없어 …· 지금 값 7", "5" 뒤에 75 가 되면서 칸 아래 빨간 글씨 "1 ~ 20 사이로 넣어 주세요", 저장 단추 꺼짐. 한 글자 지워 7 로 저장하니 "시그널 기준을 저장했습니다 — 내 기준으로 다시 그립니다". 확인한 뒤 "기본값으로"로 되돌렸다. 이격도 기준 "-2" 는 받는다.
4. **지인 390×400(키보드가 올라온 창)에서 1번 다시**: 알림 줄이 맨 위(y 8~66)에 보이고, 고치는 칸(y 178)도 같은 화면에 함께 보인다. 라이트·다크 둘 다.

회귀(§4): 오늘 매수 시그널 → "매수 4"를 누르면 SCHD·NVDA·TSLA·삼성전자 → 차트에서 SCHD 를 고르면 2026-10-22 표시(통과). 100만 원(1000000) 주문 가이드(통과). 폰 대시보드 "✎ 수정"에서 SCHD 수량·평단가, 삼성전자 수량(“1,600” 쉼표 포함)·평단가를 한 번에 고치면 "2종목 저장" 뒤 130주·1,600주로 바뀜(통과). 금액 가리기 → 금액은 •••••, 손익 %·수익률은 그대로 보임(통과). 폰 뒤로가기 → 고친 게 없으면 팝업만 닫히고 같은 페이지에 남음. 고친 게 있으면 "저장하지 않고 닫을까요? 저장하지 않은 종목 1개(SCHD)가 있습니다"가 뜸(통과).
승인 대기·손님: 리밸런싱의 새로 넣을 돈 칸, 매크로의 예상치 입력, 일괄 수정이 보이지 않는다. 처음 온 사람(종목 0개): 일괄 수정과 새로 넣을 돈 칸이 없고 안내와 "종목 추가하러 가기"만 있다. 종목 추가 칸에서 "-3" 을 치면 같은 알림 "보유 수량 — 빼기(−)는 넣을 수 없습니다 · 지금 값 3" 이 뜬다.
