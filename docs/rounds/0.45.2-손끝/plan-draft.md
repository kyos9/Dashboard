  - A2: 보유 수량 세 곳에서만 한 마디가 더 붙고(시험), 평단가·비중 등 다른 칸에는 없다. 화면 읽기 자리(`data-num-live`)에도 같은 글.
  - A3: 일괄 수정 저장 성공 → 연 화면에 "2종목을 저장했습니다"(시험 + 브라우저). 실패가 섞이면 팝업이 남고 알림 줄 없음.
  - A4: 360 에서 새로 넣을 돈에 1000000 → 칸 바로 아래에 "₩1,000,000 를 넣어…" 가 칸과 같은 화면에 보인다. 빈 칸이면 전 문구.

## C. 차트를 손가락으로 — 중간

0.45.1 사용자 확인·검토에서 남은 차트 셋(`BCD-user.md`, ROADMAP 0-1).

| # | 지금 | 바꾸면 |
| --- | --- | --- |
| C1 | 0.5초 안에 **30px 넘게 떨어진** 곳을 다시 누르면 무시된다(라이브러리가 click·dblClick 어느 것도 안 보낸다) | 차트 칸의 **포인터 이벤트를 직접** 받는다: 누른 자리에서 10px 안에 0.5초 안에 뗀 것을 "탭"으로 보고 그 x 의 날로(`timeScale().coordinateToLogical`). 라이브러리의 click·dblClick 구독은 뗀다(둘이 같이 돌면 한 탭에 두 번 움직인다). 마우스 클릭도 같은 길 |
| C2 | 1년 보기에서 1px ≈ 하루 — 손가락으로 **바로 옆 거래일**을 짚기 어렵다 | 차트 위 한 줄(`chart-readout`) 옆에 **◀ ▶ 하루씩** 단추 둘(44px, 읽기 이름 "하루 앞"·"하루 뒤"). 가리킨 날(없으면 마지막 날)에서 한 거래일 옮기고 십자선도 그 날로. 끝에서는 그쪽 단추를 끈다(`disabled`) |
| C3 | 손가락으로 밀면 날짜가 따라오지 않고 **차트가 통째로 밀린다** — 되돌리는 단추가 없다 | 밀기·벌려 키우기(라이브러리 그대로)로 보이는 구간이 바뀌면 차트 오른쪽 위에 "**전체 보기**" 단추(44px)가 뜨고, 누르면 처음처럼 전체(`fitContent`)로 돌아가며 단추가 사라진다. 날짜를 따라오게 하는 길은 풀이에 한 줄: "길게 누른 채 밀면 날짜가 따라옵니다"(라이브러리의 길게 누르기 — 이미 된다, 확인한다) |

- 규제 영향: 없음(차트의 점·색·범례 그대로).
- 데이터·API: 없음.
- 화면 말: "하루 앞·하루 뒤"·"전체 보기"·길게 누르기 풀이 → 용어집 "차트" 줄, README 0.45.2.

- 쓰는 곳 둘(대시보드 차트 팝업 `ChartModal`, 차트 화면 `HistoryChart`) — 부품 하나(`PriceChart`)라 같이 바뀐다.
- **완료 조건**
  - C1: Playwright 390(터치 켬)에서 0.3초 간격 두 탭이 **60px·200px** 떨어져도 두 번째 탭의 날이 읽기 줄에 나온다. 마우스 클릭(1400)도 그 날. 밀기(누른 채 40px 이동)는 날을 바꾸지 않는다. 시험: 포인터 이벤트 목으로 탭·밀기·늦게 떼기.
  - C2: ◀ 를 세 번 → 세 거래일 앞(주말 건너뜀 — 데이터의 날 기준). 마지막 날에서 ▶ 꺼짐, 첫날에서 ◀ 꺼짐. 종목·기간을 바꾸면 마지막 날에서 다시. 시험 + 브라우저. 360 에서 읽기 줄과 단추가 가로 넘침 없이(두 줄이 되어도 된다).
