# 0.45.2 C(차트) — 사용자 확인 다시 보기

화면만 보고 써 봤다(코드는 읽지 않음). 가짜 서버 8173, Playwright Chromium.
폰은 `hasTouch·isMobile`. 탭은 CDP `Input.dispatchTouchEvent`(80ms 누름)로 하고 `touchscreen.tap` 과 섞어 썼다. 밀기·길게 누르기·두 손가락도 CDP 로 했다.
