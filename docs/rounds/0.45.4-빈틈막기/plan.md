## 항목 (최종)

- **A 방침과 중립 틀**
  - 방침 3절을 정리·진단·종목 분석 세 갈래로 적는다. 4절에 기기 저장 목록을 더한다. 시행일을 고친다.
  - 허용 목록 방침 시험을 둔다.
  - 종목 분석 지시문: 주인은 바이트 그대로다. 사용자는 중립 틀이고, 6절은 "이미 담은 종목 중 같은 업종"이다. 평가·권유·목표가 금지, 배수 범위 없는 시나리오.
  - 화면 소개 글과 빠른 요청을 둘로 나눈다. README와 app_settings 설명, 용어집, ROADMAP 3절·9-8 줄을 고친다.
- **B 웹 보안**
  - 헤더: nosniff, Referrer-Policy same-origin, X-Frame-Options DENY, Permissions-Policy, HTTPS면 HSTS 30일, CSP(해시는 LF로 재고 mtime 바뀌면 다시 잰다, `SIGNAL_DASHBOARD_CSP=off`).
  - `/docs`·`/redoc`을 끄고, openapi를 `/api/openapi.json`(로그인 뒤)으로 옮긴다.
  - 입력 한도(위 표)와 본문 1MB를 둔다.
  - logout-all: 구글 모드만, 승인된 사람만. epoch를 1 올리고, 구독을 모두 지우고, 쿠키를 지운다. 폰은 계정 메뉴, PC는 이름 칩 메뉴.
  - fastapi 0.120.4와 starlette 0.49.3을 고정하고, cryptography를 고정한다. dependabot을 둔다.
  - DEPLOY에 HSTS·CSP 끄기를 적는다.
- **C 목표 0%**
  - 팔기 줄에 꼬리, 둘 이상이면 모은 줄.
  - 목표 없이 수량을 넣고 추가하면 남는 경고를 띄운다. 추가 알림은 이름으로 말한다.

**완료 조건** — 초안 그대로에 아래를 더하고 바꾼다.
- A: 화면 소개 글이 사용자에게 편입·알파·익스포저 0이다. 허용 목록 시험이 있고, 금액 열쇠를 더하는 뮤테이션과 방침에서 "종목 분석"을 지우는 뮤테이션이 잡힌다. system grep 0, 주인 바이트가 같다.
- B:
  - `/docs`·`/openapi.json`에서 스키마 JSON이 나오지 않는다.
  - CRLF와 mtime 시험이 있다.
  - 주인 31개 이상 순서 시험, 옛 긴 값 읽기 시험이 있다.
  - logout-all: 구글 아님이면 400, 대기면 401, 구독이 지워지는지, 남의 것은 그대로인지.
  - Playwright CSP 위반 0이다(1400·390·360 × 두 테마).
  - API 모양 빠짐 0이다.
- C: 조건 시험(팔기 줄만, 모은 줄, 매수만 보기 없음)이 있다. 남는 경고 시험이 있다. 360 첫 화면 요약 카드 위치가 같다.
