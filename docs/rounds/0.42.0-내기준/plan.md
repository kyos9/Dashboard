## A. 시그널 기준 내 설정

- 바꿀 수 있는 값

  | 값 | 기본 | 쓰는 조건 | 받는 범위 |

  | ADX 기준 | 20 | 매수 "추세 형성" | 10 ~ 40, 0.5 단위 |
  | 거래량비 | 1.1 | 매수 "변동성 또는 거래량" (매수만) | 0.5 ~ 3.0, 0.05 단위 |
  | 이격도 기준 | 0 | 매수 "이격도" | −20 ~ 0 (%), 0.5 단위 |

- 데이터: `user_settings.signal_thresholds` JSON nullable(사용자별, NULL=기본). 0013. 공용 표는 그대로.
- 계산: 기본인 사람은 지금 길(`signal_daily`) 그대로. 바꾼 사람만 `indicator_daily`(+ 비교 기간을 바꿨으면 `price_daily` 종가)에서 다시 판정. 캐시 위.
- 쓰이는 곳(A-결정 1): 카드(오늘·조건·마지막 매수일), 설명 줄·열 머리·칩·신호등, 차트 점, 매수 알림, 리밸런싱 "이번 기간 어깨매도". AI 는 A-결정 2.
- API: `/api/signal-rules` 에 `custom`·`defaults`·`thresholds` 더함(MINE). `PUT`·`DELETE /api/signal-thresholds`(MINE). 응답 필드는 더하기만.
- 화면: "시그널 기준" 버튼(시그널 보기 위쪽, 신호 요약 카드) → 팝업 넷 + "기본값으로". 바꾼 사람에게만 "내 기준" 표시와 요약 카드 한 줄. 옛 서버(0.40: 404, 0.41: `custom` 없음)면 버튼 숨김.
- 방침: "내가 입력한 것"에 시그널 기준. AI 쪽 문장은 결정 2 대로.

- 되돌리기: 사용자는 "기본값으로". 서버는 DEPLOY 의 0012 내리기 순서.
